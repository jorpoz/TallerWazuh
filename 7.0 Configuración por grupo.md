Por ejemplo, vamos a modificar para que en Windows coja los eventos del sysmon y en usuarios para que monitorice ciertos archivos


En el grupo de linux modificamos la configuración para que monitorice el `/home/*/.ssh/` y el `/root/.ssh/` por ejemplo.
Y en los windows para que monitorice el directorio de **Documents** de los usuarios y el cambio del fichero de hosts. Cuidado si el sistema está instalado en español, se puede cambiar o añadir **Documents** por **Documentos**.

![Imagen](imagenes/Pasted%20image%2020261009105723.png)

y pegamos la config:
```
<agent_config>
    <!-- Shared agent configuration here -->
    <syscheck>
      <directories check_all="yes" report_changes="yes" realtime="yes" whodata="yes">C:\Windows\System32\drivers\etc</directories>
      <directories check_all="yes" whodata="yes" report_changes="yes">C:\Users\*\Documents</directories>
      <!--directories><FILEPATH_OF_MONITORED_DIRECTORY></directories-->
    </syscheck>
  </agent_config>
```

Para la monitorización de sysmon (grupo windows):
```
<agent_config>
    <!-- Shared agent configuration here -->
    <localfile>
      <location>Microsoft-Windows-Sysmon/Operational</location>
      <log_format>eventchannel</log_format>
    </localfile>
  </agent_config>
```

Y para los linux:
```
<agent_config>
    <!-- Shared agent configuration here -->
    <syscheck>
      <directories check_all="yes" report_changes="yes" realtime="yes" whodata="yes">/home/*/.ssh/</directories>
      <directories check_all="yes" whodata="yes" report_changes="yes" realtime="yes">/root/.ssh/</directories>
      <!--directories><FILEPATH_OF_MONITORED_DIRECTORY></directories-->
    </syscheck>
  </agent_config>
```

Una vez grabado el fichero podemos revisar en los agentes donde se ha aplicado:
```
grep -R -i ssh /var/ossec/etc/*
cat /var/ossec/etc/shared/agent.conf
```
