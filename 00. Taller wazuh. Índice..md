## 1.0 Componentes

¿Qué es wazuh?
==por que me mola y que aporta.==
Componentes:
- **Indexer**: the Wazuh indexer is a highly scalable, full-text search and analytics engine.  This central component indexes and stores alerts generated by the Wazuh server.
- **server**: The Wazuh server analyzes data received from the agents and processes it using threat intelligence.  A single server can analyze data from thousands of agents, and scale when set up as a cluster. It is also used to manage the agents, configuring them remotely when necessary.
	- **Master node**
	- **Worker node**
- **dashboard**: The Wazuh dashboard is the web user interface for data visualization, analysis, and management.  It includes dashboards for regulatory compliance, vulnerabilities, file integrity, configuration assessment, cloud infrastructure events, among others.

## 2.0 Entorno de despliegue.
Se puede elegir instalar los componentes en un único host, en varios o en contenedores, cada uno tiene sus ventajas e inconvenientes.
Elegimos docker (bien en un único host o en swarm) por la facilidad de replicar el trabajo y porque en una charla de RedIRIS lo aconsejaron.
Hay que tener en cuenta las necesidades de hardware que tiene que soportar el host anfitrión.
Para una PoC, podemos ajustar más los requisitos y si vemos que nos gusta, al tenerlo en docker solo tenemos que copiar las definiciones de servicio y dar más recursos para migrarlo.
