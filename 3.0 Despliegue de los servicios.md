Los contenedores escuchan en varios puertos, se usan para:
#### Exposed ports

|Puerto|Protocolo|Uso|
|---|---|---|
|1514|TCP|Comunicación de los agentes con el servidor (manager) para enviar eventos. También lo usa el servidor para recibir eventos de agentes en modo seguro.|
|1515|TCP|Servicio de registro (enrollment) de agentes, mediante `authd`. Solo se usa al dar de alta un agente nuevo.|
|514|UDP|Recepción de mensajes syslog de dispositivos remotos (firewalls, routers, etc.) que no pueden usar agente. Requiere configurar `<remote>` con `syslog` en `ossec.conf`.|
|55000|TCP|API RESTful del servidor Wazuh (gestión de agentes, reglas, decoders, configuración, etc.). Es la que usa el dashboard para comunicarse con el manager.|
|9200|TCP|API REST del indexador Wazuh (basado en OpenSearch). Es la que usan Filebeat (para enviar alertas) y el dashboard (para consultar datos).|
|443|TCP|Interfaz web del dashboard de Wazuh por HTTPS.|
