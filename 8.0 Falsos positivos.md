Cuando se pongan muchos equipos y más si configuramos el sysmon nos vamos a encontrar con falsos positivos.
Vemos como crear reglas para evitar estos falsos positivos

Por ejemplo, generamos un evento al crear un usuario en linux:

`useradd foo`

Y vemos el **threat Hunting** los eventos generados:

![Imagen](imagenes/Pasted%20image%2020261015224954.png)

Podemos ver detalles del evento:

![Imagen](imagenes/Pasted%20image%2020261015225058.png)

Y con esos detalles podemos crear una regla para evitar que genere una alarma.
Las reglas en la consola las podemos encontrar en:

![Imagen](imagenes/Pasted%20image%2020261010005407.png)

Podemos filtrar por las reglas personalizadas.
Creamos un nuevo fichero para guardar los falsos positivos
![Imagen](imagenes/Pasted%20image%2020261015225315.png)

Le damos el nombre que queramos y generamos la regla:
```xml
<group name="adduser,">
  <!-- Ignorar alta de usuario -->
  <rule id="100100" level="0">
    <if_sid>5902</if_sid>
    <hostname>^wazuh-taller$</hostname>
    <user>^foo$</user>
    <description>Alta de usuario foo de pruebas ignorada.</description>
  </rule>
</group>
```
![Imagen](imagenes/Pasted%20image%2020261015234552.png)

Le damos a "reload" y luego vemos el fichero creado:
![Imagen](imagenes/Pasted%20image%2020261015232217.png)

```
ll /var/lib/docker/volumes/wazuh_wazuh_etc/_data/rules/falsos_positivos_rules.xml
cat /var/lib/docker/volumes/wazuh_wazuh_etc/_data/rules/falsos_positivos_rules.xml
```

![Imagen](imagenes/Pasted%20image%2020261015234654.png)

Para crear la regla hay que tener cuidado con los campos, algunos son estáticos y otros dinámicos y se expresan de distinta forma.
Para conocer mejor la sintaxis correcta es necesario acudir a la documentación. Creo haber leido que en la próxima versión de wazuh las reglas se van a poder crear de forma gráfica, por lo que lo mismo se simplifica bastante.

Las id de las reglas tienen que ser únicos. Y para las definidas de forma personalizada se establece por encima de 100000.
el **if_sid** hace referencia a que es una regla hija y con **level="0"** le decimos que la silencie. si ponemos el level a 16 debería mostrar la alerta como crítica.
