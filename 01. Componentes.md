¿Qué es wazuh?
Bueno, pues si miramos la definición Wazuh es un SIEM, es decir, que recibe eventos de distintas fuentes, los correlaciona y genera alertas de seguridad.
Yo lo uso para tener visibilidad de lo que pasa en mi en mi red. Con Wazuh tengo centralizados los eventos más relevantes de los distintos equipos que forman parte de mi organización, me proporciona una enumeración de los equipos, software y servicios y me dice que vulnerabilidades están presentes en ellos.

Y todo esto usando software libre, con la agilidad que ello da. Puedes personalizar configuraciones en función de distintos tipos de equipos, puedes crear reglas nuevas y ajustarlo a tus necesidades, puedes generar gráficas y cuadros de mando para tomar decisiones, como por ejemplo, que servidor necesita ser parcheado antes.
Además también puede realizar acciones a través de los agentes o scripts, lo que aporta funcionalidades de XDR, pudiendo responder a los eventos recibidos.

Para realizar todas estas funciones Wazuh usa distintos componentes:
- **Indexer**: Usa OpenSearch para guardar los eventos y alertas generados. Permite realizar búsquedas de forma rápida dentro de esos documentos guardados. Se pueden desplegar varios indexer para repartir la carga de indexado y consulta. *the Wazuh indexer is a highly scalable, full-text search and analytics engine.  This central component indexes and stores alerts generated by the Wazuh server.*
- **server**: Es la parte más importante de la plaforma. Recibe los eventos de los agentes, interpreta la información y aplica reglas para identificar eventos de seguridad. Tambien se comunica con los agentes para modificar su configuración o para realizar acciones en remoto.  Se pueden poner varios servidores en cluster, con un **manager** y varios **workers** para repartir la carga de analizar los eventos. *The Wazuh server analyzes data received from the agents and processes it using threat intelligence.  A single server can analyze data from thousands of agents, and scale when set up as a cluster. It is also used to manage the agents, configuring them remotely when necessary.*

- **dashboard**: Es la parte gráfica del equipo, permite ver los datos en distintos dashboard. Ya viene con los dashboard más interesantes configurados, por lo que no será necesario crear nuevos si no queremos. *The Wazuh dashboard is the web user interface for data visualization, analysis, and management.  It includes dashboards for regulatory compliance, vulnerabilities, file integrity, configuration assessment, cloud infrastructure events, among others.*
- **agents**: Es la parte que recopila la información de los equipos a vigilar. Es un software que se instala en los equipos y envía al **wazuh master** los logs del sistema, software instalado... además puede ejecutar acciones en los equipos en respuesta a algún evento.
